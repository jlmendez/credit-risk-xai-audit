# Analytical notebooks

The original audit work was notebook-heavy. This portfolio edition keeps the reusable implementation in `src/` and provides a compact Jupyter walkthrough here.

`xai_audit_walkthrough.ipynb` reconstructs the principal path from the larger source notebook: reproducible synthetic data, model fitting, group metrics, bootstrap uncertainty, threshold sensitivity and governance-oriented interpretation.

The detailed analytical concepts represented by the source notebook include permutation importance, SHAP, a LIME-style local surrogate, proxy-variable checks, mitigation analysis and model-card documentation.
